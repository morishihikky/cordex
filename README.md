![表紙](documents/slides/slide-01.png)

制作対象は、薄いタオルにアヒルが乗った小物、もこもこの泡のターバン、キュウリの目パック、バスタオルモデルの4点です。バスタブは対象外です。

バスタオルは女性4種（しなの・マヌカ・萌・ライム）、男性3種（狛乃・碼希・くうた）に対応します。

小物の画像はAI生成の参考イメージです。アバター画像は各モデルのBOOTH販売ページからの参照画像です。
